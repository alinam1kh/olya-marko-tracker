# Трекер для Олі й Марка

Сімейний фінансовий трекер на Beancount 3 і Fava (HW #3, Warsaw IT School 5.0). Марко відкриває його з телефона, входить за паролем, дивиться звіт за місяць і додає готівкові витрати.

**У репозиторії лише штучні дані з умови завдання**: виписка Олі (`data/statement.csv`) і Марка (`data/marko/statement.csv`). Паролів і ключів тут немає.

## Перевірка однією командою

```bash
uv sync
uv run python check.py
```

Команда заново імпортує обидві виписки, запускає bean-check для обох журналів і друкує контрольні цифри. Очікуваний результат:

| | Змінні, серпень | Змінні, вересень |
|---|---|---|
| Оля | 2 195,21 зл | 2 582,42 зл |
| Марко | 1 855,57 зл | 2 432,83 зл |

Наприкінці має бути `УСЕ ЗБІГАЄТЬСЯ`, а bean-check — мовчати. Якщо щось не збігається, команда завершиться з кодом 1.

## Що де лежить
- `main.beancount` — журнал Олі (рахунки, 4 збережені запити, звірка з банком); `import.py` — імпорт її виписки.
- `marko.beancount` — журнал Марка з тими самими запитами; `import_marko.py` — імпорт його виписки (інший формат банку: «;», кома в сумах, від новіших до старіших).
- `marko-cash.beancount` — готівка, яку Марко додає з телефона. Імпорт цей файл не чіпає, тож записи зберігаються.
- `rules.csv` — правила категорій для обох (шаблон → рахунок → чи фіксована витрата).
- `wsgi.py` — вебзастосунок: Fava з двома журналами, вхід за паролем, лише HTTPS.
- `check.py` — перевірка однією командою.

## Звіт за місяць
Головна сторінка (`/`) — мобільний звіт (`ui.py`, дані рахує `report_data.py` з журналів при кожному відкритті): перемикач Марко / Оля, місяць, відкладено й норма заощаджень, витрати по тижнях, фіксовані й змінні, категорії.

Fava лежить на `/fava`: зліва розділ «Запит» зі збереженими запитами «1 Витрати за категоріями», «2 Норма заощаджень», «3 Фіксовані і змінні», «4 Без категорії».

## Як додати готівкову витрату з телефона
У звіті кнопка **«Додати витрату»** (відкриває Fava) → маленький **+** біля «Редактор» → дата, опис, рахунок витрати (наприклад `Expenses:Продукти`) і сума, другий рядок — `Assets:Готівка` без суми → **Зберегти**. Запис потрапляє в `marko-cash.beancount` і одразу видно і в звіті, і в запитах.

## Нова виписка раз на місяць
1. Вивантажте CSV з банку (Оля — `data/statement.csv`, Марко — `data/marko/statement.csv`).
2. На PythonAnywhere: **Files** → замініть файл у потрібній папці (**Upload a file**).
3. **Consoles** → у папці проєкту `~/.virtualenvs/tracker/bin/python check.py` — імпорт, звірка з банком і контрольні цифри.

## Розгортання на PythonAnywhere (безкоштовний акаунт)
1. Bash console: `git clone <цей репозиторій>`, `cd <папка>`, `mkvirtualenv tracker --python=python3.12`, `pip install -r requirements.txt`.
2. `python import.py && python import_marko.py` — збирає журнали з виписок.
3. Створіть `.env` за зразком `.env.example` (логін і пароль трекера). Файл лишається лише на сервері.
4. Web → Add a new web app → Manual configuration (Python 3.12) → Virtualenv: `tracker`. У WSGI-файлі залиште лише:
   ```python
   import sys
   sys.path.insert(0, "/home/<імʼя>/<папка>")
   from wsgi import application
   ```
5. Web → **Force HTTPS: Enabled** → Reload. Трекер відкривається на `https://<імʼя>.pythonanywhere.com`.

Безпека: без входу трекер не показує жодних даних; логін і пароль лише в `.env` на сервері; HTTP перенаправляється на HTTPS; у репозиторії й на сервері лише штучні дані з умови.
